## 🏟️ Match Highlights

### 🥇 [ExamSyncAi](https://github.com/VishalDhariwal/ExamSyncAi) — *the playmaker*
RAG-powered exam generation and automated evaluation. Retrieval, generation and grading all wired into one platform.
`LangChain` `LangGraph` `Groq` `ChromaDB` `Tree Index` `Python`

### 🥈 [Fake News Prediction App](https://github.com/VishalDhariwal/Fake-news-prediction-app) — *the enforcer*
CLIP ViT-B/32 + XGBoost, checking whether an image and its caption actually agree. Catches the ones that dive.
`CLIP` `XGBoost` `TypeScript` `Multimodal ML`

### 🥉 [Multimodal Emotion Detection](https://github.com/VishalDhariwal/Multimodal_Emotion_Detection) — *reads the whole pitch*
BERT text embeddings fused with MFCC audio features to classify emotion from conversation. Two signals, one read.
`BERT` `MFCC` `Deep Learning` `Jupyter`

### 🏅 [Machine Failure Prediction](https://github.com/VishalDhariwal/Machine-Failure-Prediction-) — *the sweeper*
End-to-end machine health monitoring — predicts equipment failure and flags sensor anomalies before the breakdown.
`ML` `Anomaly Detection` `JavaScript` `Sensor Data`

### ⚽ [eFootball Arena](https://github.com/VishalDhariwal/eFootball_Arena) — *home fixture*
Full platform for running eFootball tournaments: brackets, players, organizers, the lot. Football, but it's also the codebase.
`TypeScript` `Full Stack` `Tournament Management`
